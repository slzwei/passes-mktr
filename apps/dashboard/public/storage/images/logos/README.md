# Logo Images Directory

Place your Apple PassKit logo images here.

## Apple PassKit Logo Requirements

### Standard Logo Images

- **@1x**: 160x50px
- **@2x**: 320x100px
- **@3x**: 480x150px
- **Format**: PNG with transparency preferred

## Example Logos

You can create logos for different business types:

- `coffee-shop-logo.png` (160x50), `coffee-shop-logo@2x.png` (320x100), `coffee-shop-logo@3x.png` (480x150)
- `restaurant-logo.png` (160x50), `restaurant-logo@2x.png` (320x100), `restaurant-logo@3x.png` (480x150)
- `retail-logo.png` (160x50), `retail-logo@2x.png` (320x100), `retail-logo@3x.png` (480x150)

## Logo Guidelines

1. **Dimensions**: Exact sizes as specified by Apple PassKit
2. **Format**: PNG with transparency for best results
3. **Style**: Clear, recognizable at small size
4. **Colors**: Should work well on colored backgrounds
5. **File Size**: Keep under 50KB for fast loading

## Creating Logos

You can create logos using:

- Design tools like Photoshop, Figma, or Canva
- Vector graphics tools
- Logo generators
- Business branding materials

Make sure your logo is clearly visible at 50x50px size and works well against the pass background color.
